This is a complete, self-contained restaurant website template designed for speed, simplicity, and ease of use. Built entirely with vanilla HTML, CSS, and JavaScript, it requires no external frameworks (like Bootstrap or Tailwind), no npm packages, and no build processes.
Everything you need—from the responsive navigation and smooth scrolling down to the cohesive color scheme—lives inside one single index.html file.
This makes it the perfect starter template for small business owners, freelancers, or junior developers who want to get a high-quality restaurant, cafe, or bar website live on the internet in minutes. Just change the CSS color variables, swap the placeholder text for your real menu, add your photos, and deploy it instantly to GitHub Pages, Netlify, or any standard web host.


## Deployment

Because this template is built using static HTML and CSS, it can be hosted online for free with no build steps required.

### Method 1: GitHub Pages
1. Fork this repository to your own GitHub account using the Fork button at the top right.
2. In your forked repository, navigate to the Settings tab at the top.
3. In the left-hand sidebar under Code and automation, click Pages.
4. Under Build and deployment, locate the Branch dropdown menu.
5. Select the main branch, keep the folder directory as / (root), and click Save.
6. Your website will be live at your GitHub Pages URL within a few minutes.

### Method 2: Netlify or Vercel
1. Log into your Netlify or Vercel account.
2. Select the option to import a new project from Git and connect your GitHub account.
3. Choose this repository from your list.
4. Leave the build command and publish directory fields completely blank.
5. Click Deploy to publish your website immediately.
